# 游戏纯净模式

2026-09-14。用户截图约736×439，小窗口中左上大信息卡、右上暂停、底部键位/重开遮挡赛道。要求设置内提供纯净模式，只显示计时器，并检测小屏自动打开。

## 行为

- 设置新增「纯净模式」，用紧凑三选项「自动 / 开启 / 关闭」，默认自动。自动模式在实际可用游戏窗口宽≤1200 CSS px或高≤600 CSS px时启用，大窗口自动恢复完整HUD。不要用设备型号或仅pointer:coarse判断，桌面缩小窗口同样适用。
- 手动开启/关闭优先于尺寸检测，自动resize只计算实际模式，不覆盖用户选择或反复写存档。选择持久化在当前v3设置，旧存档缺字段/非法值回退auto，恢复默认也恢复auto，旧设置与所有历史成绩保持。
- 监测初始尺寸、resize、横竖屏及必要visualViewport变化；尽量复用App现有viewport监听，避免重复订阅，卸载释放。临时缩放/键盘不改变已保存偏好。
- 正在游戏的纯净HUD只显示一个紧凑计时器，左上安全区定位，仅时间数字，小面积底色确保水面可读；无“本次用时”、关卡/编号/目标/CP/掉落计数、进度条、键位提示、独立暂停按钮或重开按钮。
- 计时器本身是可点击/触控/键盘激活的暂停入口（至少44px触控高度，视觉仍只显示时间），aria-label说明暂停，不添加常驻文字/图标。调用已有暂停流程，暂停菜单内继续/重开/设置均保留；Esc/R既有键位保持。不要隐藏全部入口让用户无法关纯净模式。
- 手机摇杆与刹车属于实际输入，必须保留，不能因只显示计时器而让游戏无法操作；触控清零/竖屏暂停/横屏继续逻辑保持。纯净模式只裁减常驻HUD，不隐藏暂停/结算/设置、加载失败或必须处理的旋屏提示。
- 首页、图鉴、成绩页不受纯净模式裁减。只改HUD和设置，不改游戏镜头/控制/物理/关卡。仍不自动测试/构建/类型检查/浏览器试玩，不Git写入或部署；若补存储回归用例，写明未执行。
