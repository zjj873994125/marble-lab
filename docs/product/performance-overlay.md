# 实时性能信息

2026-09-14。用户明确要求增加性能信息：设置开关默认关闭；主动开启后右上显示FPS/帧耗时，并支持绘制调用、三角面等真实渲染统计。纯净模式下仅主动开启才显示。

## 显示与设置

- 设置新增「显示性能信息」开关，settings.showPerformance严格布尔值，默认false，缺失/非法回退false；当前v3持久化并纳入恢复默认，不影响已有纯净模式/七主题/水速和所有成绩桶。
- 开启后主游戏Application存在且完成有效采样时，右上紧凑小面板第一行 `60 FPS · 16.7 ms`；第二行小字 `绘制 120 · 三角面 21.8万`，不显示额外图表/设备信息/长说明。数字为示例，禁止硬编码读数。等宽数字、少量透明底、pointer-events:none、安全区边距，避开完整HUD暂停按钮/首页右上按钮；纯净模式计时器仍在左上。
- 小屏手动开启仍能显示，纯净模式不会自动打开性能统计；关掉开关立即隐藏并停采样，不能后台一直刷新Vue。面板不挡摇杆/刹车/暂停入口。
- 首页与挑战中的主场景可显示；离开主场景进入静态图鉴列表等没有该Application时清空/隐藏，不继续显示上一关数据。本轮不要求给图鉴独立预览新建另一套采集。

## 数据口径与生命周期

- 复用PlayCanvas实际渲染帧事件/当前2.22.1统计接口，CODE先核对本地引擎源码的字段与计数更新时间；FPS按真实墙钟完成渲染帧统计，不从游戏计时或受timeScale影响的dt计算，不启动与真实绘制无关的额外rAF计数冒充引擎帧。
- 约每.5–1秒汇总一次发给Vue，FPS保留整数或一位、帧间隔ms一位；文档明确ms为平均帧间隔，不标成GPU耗时。绘制调用/三角面使用真实渲染统计（含哪些pass以引擎定义说明），不是全部模型文件静态面数相加；拿不到时显示“—”或省略，不能造0。
- 暂停时若画布仍实际渲染可继续统计，不能因app.timeScale=0除零。后台隐藏/渲染停下/场景卸载/关闭开关时重置窗口与读数，恢复从新样本计算，不把后台间隔当长期卡顿或继续显示过期高FPS。初次采样有明确占位，不残留上一关值。
- 不把每帧统计写入state持久化/成绩，只持久化用户开关；避免每帧新数组/对象与DOM更新、额外渲染或常驻重型性能库。卸载/失败/取消路径释放监听；开关和切关反复操作不叠加监听。
- 不改渲染帧率上限、物理步进、玩家控制、镜头或画质策略。本轮只观测，不自动调画质/降面数。
