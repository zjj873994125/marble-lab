# 赛道皮肤 · 四套场景主题

2026-09-14。用户讨论赛道皮肤后明确“设计一下然后开始开发这个”。本轮授权设计并实现赛道主题：经典奶油、工业钢铁、冰川蓝白、黑金竞技。暂不扩展小球皮肤/商城/解锁，不开展顶级难度关卡实现；LEVEL长关仍只设计。

## 用户流程与范围

设置新增「赛道皮肤」，四个紧凑2×2可选卡片，只有一张代表性赛道配色缩略图、中文名字和选中标识。沿用现有浅色设置样式，不在玩法画面增加皮肤按钮/英文/参数/长说明，不新增常驻WebGL预览。全部直接可选。

选择后当前已加载场景即时换材质，首页和游戏都生效；游戏中打开设置仍先暂停，切皮肤不重载场景、不重开、不改机关相位、计时、CP、掉落、输入或镜头。设置自动保存，刷新/切关沿用；默认和恢复默认均classic，缺失/非法值回退classic，保留所有既有设置与成绩桶。选择与纯净模式互不影响，1200/600阈值保持。

覆盖三关的静态台面/侧边、护栏支撑、锤/十字/升降/横移、五机关共享库、基础外观回退及池水/池边。保护小球自身钢材反射、CP/终点/警示语义、UI品牌及HUD；这不是全场景按颜色一键替换。

## 视觉方案

候选设计token供ART校正，CODE可以先按此建立配置，ART确定后由CODE收敛到最终palette。

- **classic / 经典奶油**：恢复每个资源原始材质，象牙台面、陶橙边缘、石墨结构、现有蓝绿水面。不能把所有原材质强行变成一种“近似奶油”，从其他主题切回需完整恢复原PBR值。
- **industrial / 工业钢铁**：冷银灰台面 `#A8B4BD`、安全黄边缘 `#F2B635`、深石墨结构 `#303C47`、合金 `#C5D1D7`、深蓝水 `#163B53`。台面适度金属/较粗糙，避免刺眼镜面；橡胶/刻度仍能识别。
- **glacier / 冰川蓝白**：冷白台面 `#E2F0F4`、冰蓝边缘 `#4FAECC`、蓝灰结构 `#304C63`、冷银合金 `#B6D2DF`、深蓝水 `#103C62`。呈冷色涂层质感，不做透明冰或改变摩擦；浅蓝检查点在深蓝环境和台面上应仍有对比，必要调整皮肤装饰而不随意换检查点语义色。
- **black-gold / 黑金竞技**：炭黑台面 `#282E35`、暖金边缘 `#D4AC53`、深棕灰结构 `#45413B`、浅金合金 `#BFA76E`、浅灰蓝绿水 `#7EA5AB`。台面使用较粗糙的深色涂层，不能黑到失去边界或让金属球轮廓消失；金色终点与金色边缘在形状/亮度上保持辨识。

四主题采用同一套现有几何，不为每套新增完整GLB/Blender文件，也不下载外部纹理。材质通过颜色、metalness、gloss/roughness等已有PBR参数区分；保留法线、标记/贴花及模型材质分区，不增加几何/碰撞。水继续使用当前动态法线/反射流程，仅主题参数变化，水速/画质/减少动态/暂停行为保持。

## CODE · 实现

1. 新增主题id/token配置及settings.trackTheme，v3加载校验、保存、恢复默认和旧数据兼容。类型/参数集中维护，不散落Vue和加载器。
2. 在现有资源加载/实例挂载边界按语义材质名映射，读取当前真实GLB名称和ART映射，包含可能的Blender数字后缀；不可单凭原RGB猜用途。未知材质保留原值，球/检查点/终点/警示指示显式排除。
3. 原始材质基线完整记录。每个Application/资源作用域只创建必要主题材质实例或在确定独占材质上更新，切换不累积克隆；不能修改共享模板后污染别的场景或毁掉原材质。迟到GLB使用最新主题，退出/失败/取消路径释放自有克隆且不误销毁共享纹理/资源。
4. 正式模型和primitive fallback一致，静态/动态所有加载入口都接，不只改程序生成台面。图鉴3D预览采用当前主题；静态图片若无法实时着色应明确选用经典展示，不把图片颜色冒充当前主题。优先让主题卡/LevelThumbnail等代码生成图使用同一token，避免新建大量渲染包；不要用CSS全图滤镜误染小球/水/标记。
5. 设置四卡选中即更新，无新增应用/付费/解锁步骤。复用当前设置暂停语义，切换不销毁游戏，不把applySettings的副作用放大到重开。
6. 交付说明覆盖三关/动态图鉴/fallback，说明无测试的边界。按用户现有偏好不自动test/build/typecheck/浏览器试玩、不Git写入或部署。必要已有保存用例可更新但未运行必须注明。

### 水色区分修订

用户反馈皮肤似乎没改水色，并明确水不一定是蓝色。当前源码有水材质原位注册与主题refresh链路，但此前多数water token仍是深蓝/深青，主题区分不足；源码接入不能替代实际呈现验证。本轮定向修改水色及必要水面反射色处理，不改已确认七款台面/结构/机关和玩法。

ART保留classic原水色，给其余六款设计明显不同的水色：industrial琥珀棕、glacier靛紫、black-gold浅玉绿、violet深梅紫、pink莓红、yellow翡翠绿。方向可为赛道/球/标记对比合理微调，不能又全部回到近蓝色。候选参考分别#765A3C/#34325E/#94B9A0/#492B68/#69344F/#22584B；同时保证与对应台面有亮度差，不能同色融在一起。更新现有ART文档water token与同名七款对照图，其他角色保持。

CODE复核当前所有实际water材质与主题刷新，不仅改卡片颜色；设置切换、迟到/切关、低高画质、classic恢复、动态图鉴以及生成图同源。若固定蓝色环境反射过强掩盖主题基色，在水专用反射路径作最小中性化/按主题调色，保护classic原效果、纹理资源所有权、水速和连续相位，不影响钢球反射，不重建模型或重开局。不得用CSS滤镜整体染场景，不能把水换成不动的哑光色板。CODE处理必要回归覆盖并准确说明未运行项目，保留CI浮点修复和所有其他本地修改，无Git/部署。

### 用户最终纠正与入口迁移

黑金竞技的水必须为**金黄色**，工业钢铁为**近黑色黑海**，覆盖上一版浅玉绿/琥珀棕。水仍有可见流动和反光，工业深水与钢蓝台面保持对比，金水与黑台面/金属球有清楚轮廓；非这两款的配色保持。ART定向修订原water token和同名七款图，CODE按新值收口实际水与所有生成缩略图。
