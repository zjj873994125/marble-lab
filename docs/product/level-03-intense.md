# 第三关再次加强：快动作与真实失衡

2026-09-14。用户试玩反馈：推墙仍慢、翻板闭合慢、滚筒还要更快、吊桥幅度要更大、跷跷板没有掉落风险。本轮授权实施，不止提案。上轮保留的吊桥10°和跷跷板±8°/板宽2.2米不足以满足反馈，本轮允许定向修改这两项模型及接岸几何。

## 明确体验与候选量级

- 推墙：推出从.45秒向.18–.22秒调，回收从.65向.25秒调；停留/预告独立安排，保留可识别预告。不能只缩等待而保持推头慢动。CODE按固定物理步长、球径与推头厚度分析快速扫掠是否漏碰撞，有明确问题则先修实现或选择可用最快值，不偷偷加推球力。
- 翻板：用户明确要求“闭合也慢”，回位阶段从.6秒向.18–.22秒调，下翻约.2秒。闭合停留与闭合动作是不同字段，不误把缩短停留当加快合板。安全停留暂保留可通过的一轮，避免周期快到只能蒙撞。
- 滚筒：从−1.8向−4.5rad/s调，实际旋转接触、图鉴同步。此为上轮的2.5倍，不再用初版倍数包装小幅变化。
- 吊桥：目标25°左右、周期约2.8–3.2秒，要求明显侧移和倾斜；若现有岸口/门架不足，LEVEL与ART扩大运动净空、重做对应接岸，而不是再次把幅度限回10°。入口需择时，靠近水平时仍有真实可接上的岸。优先保留共享库根和轴心协议。
- 跷跷板：板宽向.9–1.1米、倾角向±22–25°设计，降低板自身惯量及恢复力/阻尼，使球的真实负载能明显压动板。具体质量/弹簧/阻尼由CODE与LEVEL按当前球质量与力矩推导。同步设计转轴高度、止挡和两端接岸，不能把板扎入台面或形成无跳跃能力永远上不去的台阶。用户体验目标是需控线/调整重心才能安全通过，偏线或时机不当有可见落水风险；不要只改演示动画。

候选值允许根据真实构造修订，但吊桥大幅度、跷跷板明显失衡和更窄板面是本轮核心。不能以原模型的限制把需求取消。所有候选效果尚未实测。
