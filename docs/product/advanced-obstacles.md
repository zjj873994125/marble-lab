# 复杂高难机关 · 第二批设计

2026-09-14。用户要求关卡任务继续设计复杂、高难的新机关，明确可包括蹦床、过山车、喷气。本轮授权设计，不是代码/模型实现。原13类、顶级难度关卡和第四关三路分流设计均保留，不覆盖。

## 设计目标

先交约8种新机制，其中必须有蹦床、过山车式轨道、喷气装置三类。其余优先引入不同能力，例如移动落点、传送带的真实切向接触、离心碗/漏斗轨、双轴平衡台、触发式连续坍塌/承托切换等；LEVEL自行筛选，不能把旧锤/升降/翻板提速改名充数。同类变体可以作为子方案，但不能每种变体都算一个全新机制。

追求需要提前规划、控速/控线/落点、连续决策的高难度，同时让失败原因看得懂。每个机关明确“它让球受到什么实际作用、玩家靠什么操作应对、怎样失误会掉落”。高难度不是无预告随机击落或永远没有入口窗口。

## 三个必选方向

1. **蹦床**：真实接触触发弹跳，垂直/倾斜弹射和着陆目标可设计。写清弹性/冲量与入射速度的关系、重入/连跳防抖、落地承托、速度上限影响和可控空中量；不加必须按的跳跃键、不用传送代替弹道。向上弹射属于可见机关的局部作用，不偷偷更改全关重力或玩家基础弹性。
2. **过山车式轨道**：提出重力落差、抛物跃坡、半管/倾斜弯、螺旋或完整环道的实际方案。必须读当前玩家水平限速/重力/输入/接触，区分当前能搭的静态结构与需要新局部物理模式的方案。完整环道如果在当前速度/半径下不满足贴轨条件，要给物理推导及后续能力需求，不能用隐藏磁吸/轨道锁球假装天然可行。局部导轨/管道若是方案必须可见并有真实碰撞。
3. **喷气**：可见喷嘴、风柱/横吹/脉冲时序，作用范围与受力强度衰减、启动预告、离开后惯性、多个喷嘴叠加。可以给球真实可见来源的局部力，不直接设置球位置；不能只播放粒子效果或全场暗推。手机仍可用摇杆+刹车处理，预告不依赖声音/频闪。

## 每项完整交付

- 名称/稳定设计id、一句话玩法、新增技能与旧13类差异。
- 结构示意SVG：入口出口、米制尺寸、枢轴/作用区/轨迹/落点、可触与纯装饰区别。必要顶/侧两个视图，不画成没有数据的概念海报。
- 可行的独立示范段与至少两组连续组合：可用新+旧或新+新，说明前后入口速度/位置/相位约束、短接缝和失误区。例如蹦床→移动落点→窄梁、重力曲轨→喷气横风、喷气→斜弹台等仅作候选，不能默认物理成立。
- 候选参数与推导：按现有球.85及当前源码质量/重力/限速读取，明确数值单位和假设；不硬沿用旧设计文档已过期“尚未支持五机关”结论。
- 行为状态机/触发规则/真实碰撞与局部受力方案、暂停/重开/落水/退出的必要语义。不能将设计JSON当可直接填入LevelConfig的支持字段。
- 手机控制、镜头可见性、落点预告、检查点安全位置以及物理稳定性/快速碰撞/性能负担。
- 当前已支持部分、CODE需新增能力、ART需新增/复用资产分件，实施复杂度和优先级。推荐先做2–3项，并说明原因。任何新增局部限速例外/空中控制/接触模型都只作为未来待实现协议明确列出，不现在修改玩家手感。
