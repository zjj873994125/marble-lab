# 第四关 · 三路分流设计

2026-09-14。用户澄清：原「顶级难度关卡」设计稿保留不改，刚提出的十字选择三条道路的方案另做第四关。本轮只设计，不编写正式TS、不注册第四关、不修改游戏或模型。

## 明确路线

**起点→两个机关挑战→十字旋转分流→三条道路任选其一→共同汇合→两个机关挑战→终点。** 用户的“前两关/两关后”按关卡内两个机关理解，不是先游玩两个独立关卡。公共前后各两项，分流十字单独计数。

十字有一个入口、左/前/右三个出口。玩家通过实际控球与择时下台选择道路，不设选择弹窗、随机派路或传送。给出旋转方向、四岸位置/高差和臂端进出窗口；四臂同时对齐四岸时仍需能解释实际选择行为，不误写成旋转只开放一个出口。

三路可分别侧重连续择时、窄路平衡、走线保速，均为有挑战的完整路线；任选一路通到共同末段即可，不要求遍历三路。保留短接驳二连/三连、曲折空间和高难控球，避免某条宽直支路成为明显捷径。先设计合适长度，分别统计全图独立几何总长与A/B/C单次路线长度，不能把三支路总长当一局长度；不沿用原387米/36单元数字充数。

汇合要真实可接驳，无穿模、隐形补台或支路间近道。末尾两个机关可用蛇形保速→惯性坡等连续挑战，LEVEL根据空间确定。整图列障碍覆盖/复用统计，采用现有13类资源设计，不为凑数量把公共前两项暗中扩成多个机关。

CP与终点明确分支语义：公共前段通过→完成任一合法分支→共同末段，不要求其他分支CP。重生回到本次所选支路合理位置，避免因落水被送往另一条路；分流前重选规则明确。现有线性CP/progress与旧机关单字段缺少多实例/多出口等支持，只记录未来CODE依赖，本轮不派实施。
