# 手机控制接入

手机横屏使用顶部计时/检查点/暂停、左下固定摇杆、右下小踏板。踏板仅显示44×48的内联SVG，无外围框与文字，保留88×88触控区域。暂停菜单提供重新开始、设置、操作说明和返回；操作说明打开时让出暂停弹窗，关闭说明后仍保持暂停。

## 输入边界

`src/game/input.ts` 的 `GameInput` 为 `{ x, z, brake }`。App仅在内存中持有，通过GameCanvas hook传给运行时；不写设置、成绩或实体坐标。

- 摇杆位移半径40px，死区12%，幅度连续且钳制到1；满杆仍使用原施力12与当前灵敏度，斜向不加速。
- 有键盘方向时优先键盘，两个来源不叠加力度；刹车取键盘空格或踏板的实际按下状态，继续使用原衰减系数。
- 摇杆和踏板分别捕获pointerId，松开/取消一指不影响另一指。拖出控件仍追踪，抬手、取消、丢捕获、失焦、旋屏、暂停、结算、重开、切关和卸载清零。
- 窗口宽度与coarse指针共同决定触控布局，不只用窄窗口猜测设备；键盘始终可用。竖屏进入游戏会暂停并提示横放，旋回后由用户明确继续，保留局内进度。

GameCanvas重开后再次应用当前phase，防止竖屏暂停被start覆盖。触控区使用touch-action:none，菜单/设置仍正常滚动。安全区使用env(safe-area-inset-*)，游戏高度使用100dvh。手机弹窗取消长退场动画，避免继续后遮罩仍挡住触控。
