## 根因与修复边界

### 两个检查点：圆环覆盖了真实台面没有覆盖的象限

检查点一的原显示中心 `[-1, 3.45, -4]` 恰在 L 形内凹角；`x > -1 && z < -4` 的区域没有 Track surface。检查点二原中心 `[8, 3.45, 5]` 也在内凹角；`x > 8 && z > 5` 没有台面。原半径 1 加 `tubeRadius = .045` 的外缘落入缺角，近景能看到圆环悬在台面侧壁外。这不是检查点判定错误，也不能靠关闭深度检测解决。

原环底约为 `3.45 - .045 = 3.405`，没有证据表明本问题主要由路面共面闪烁引起；主要问题是水平覆盖错误。起点与终点的圆环外缘分别为 1.245 和 1.395 米，均位于各自 4×4 米台面内，没有同类缺角越界。

**由 LEVEL-02 修复现有 ring 字段即可，不新增类型或显示架构。** 已对齐冻结数据：CP1 `[-1.5, 3.46, -3.5]`，CP2 `[7.5, 3.46, 4.5]`，半径均 `.55`。圆环外缘 `.595`，距凹角最小约 `.1121` 米，超过台面 `.065` 米倒角尺度；外缘到真实检测中心最远约 `1.3021 < 1.35` 米。底部距路面 `.015` 米。真实检查点位置、重生、顺序和容差都不动。最终还需检查未触发与已触发材质两种状态。

### 护栏交接：两个独立倒角显示网格相交

关键位置为起点内侧 `Safety rail` / Blender `Start guide.001` 与转弯下侧 `Corner rail` / Blender `Corner guide.001`，交接中心约 `x=-8.45, z=-2.45`。前者投影为 `x=[-8.51,-8.39], z=[-3,7]`；后者为 `x=[-8.7,-2.9], z=[-2.51,-2.39]`，存在完整 `.12×.12` 的交叠。两者高度相同，但分别倒角，接头内残留相交的斜面与边缘，形成穿出/叠层观感。ART-02 已从磁盘 Blender 源文件确认是两个独立倒角对象。

**由 ART-02 对已求值的原显示外形作精确并集、清除内部交叉面并核对法线。** 保留原碰撞并集的四个分支外轮廓与端部；不能将可见短端剪成 L 形后留下隐形碰撞，也不能扩出新护栏。六段实体护栏都采用橙色、原截面和固定件语言，蓝色移动平台保持。其余接头/端部逐一复核。基础回退图元先验证实际显示，只有确实无法表达修复时再考虑最小显示实现。

### 窄桥：配置连续线与模型断续线重复

原配置两条 `Bridge edge stripe` 与旧 GLB 的八个 `Narrow caution dash` 在相近的 X/Y 和相同路段同时显示。连续线 `size.y=.025`，模型断续线 `size.y=.008`，构成连续/断续叠加及局部几何交叠。单张图不能证明时间维度的深度闪烁，但双份标线来源已从配置、脚本与实际画面确认。
