# 障碍物图鉴

入口：主导航“障碍图鉴”，路由 `/#/obstacles`。当前已完成21类目录、三列卡片和点击放大的动态预览接入；高级机关预览已在隔离浏览器中逐项抽查，未读写玩家现有设置和成绩。

## 收录与用途

当前收录21类障碍。原八类为单摆锤、三锤阵、十字旋转台、交替升降板、横移平台、独木桥、蛇形回头弯和惯性坡；共享库五类为压重跷跷板、轴向滚筒桥、伸缩推墙、定时翻板和摆动吊桥；高级八类为蓄能蹦床、重力过山车弯轨、脉冲喷气阵、巡航接球斗、反转输送带桥、回旋漏斗、双轴天平台和连锁坍塌桥。分类统计为动态机关16类、路线挑战5类。

按用户最新要求精简显示：桌面三列卡片仅保留名字与障碍示意，不显示编号、类别徽标、描述、用途或能力标签。页面保留分类与搜索入口，中小屏两列或一列。点击后弹窗仅显示障碍名字和占主体的大模型预览，没有侧栏、参数、机制、策略、摆放或组合推荐文字。

`src/game/obstacles.ts` 是图鉴目录，稳定id与以下字段可供后续关卡推荐使用：category、skill、summary、motion、strategy、placement、caution、appearsIn、pairs、facts。这些内部资料与组合关系继续保留供未来推荐使用，本次只隐藏显示层；没有自动生成/编辑关卡或自动难度评分。

原八类参数从正式关卡配置读取，单锤取教学关卡，其他预览取水上冲关；共享库五类尺寸/轴心读取manifest并复用第三关正式参数。高级八类使用高级共享库的同名根与分件语义，预览姿态由 `advanced-preview.ts` 驱动，真实物理仍只在关卡运行时创建。图鉴归零展示位置/朝向并使用独立时钟，数值不写回关卡。跷跷板和双轴天平台的预览是预置姿态，不模拟球负载、弹簧和阻尼；静态路线示意也不能代替实际通关。

## 卡片与动态预览

`src/game/obstacle-scene.ts` 提供21类卡片和预览共用的场景数据；原卡片使用SVG投影，共享库五类使用从ART交付图制作的本地透明PNG，高级八类使用程序化静态构图。卡片不启动WebGL，放大时才动态导入PlayCanvas预览运行时。

三锤、十字及升降复用现有mechanism-motion中的姿态函数；单锤沿用第一关当前公式，横移使用第二关当前轴向与参数。动态件优先读取现有头/柄、十字、升降板、横移GLB，加载路径与生命周期复用model-assets。基础环境为简化构图，不从整关GLB截取或重新导出资产。

独木桥、蛇形、坡面是静态结构，小球仅用于路径示意；没有Ammo碰撞、自动代玩或速度达标判断，不能把图鉴动画当成真实物理通关。蛇形和坡面几何读取正式旋转盒体，不另维护第二份玩法布局。

预览保留播放/暂停、重播、拖动旋转、滚轮/按钮缩放和恢复视角，按钮均仅显示图标并保留aria-label，触控区域44px。移除运动徽标、底部操作说明及按钮文字；加载/失败以状态图标和无障碍名称表达。减少动态默认停止自动播放，用户可明确点击播放/重播观察；后台/失焦不推进动画，恢复不累计长间隔。打开图鉴时卸载背景游戏Canvas，返回原页面再按选中关卡加载；图鉴预览不启动挑战、不读取输入施力、不写设置或成绩。

同一图鉴页面保留一个预览Application和会话资源池。旧五机关与高级八机关各自整包下载/解析一次，并各自构建一个不挂场景的模板；选中机关仅克隆目标根子树，网格和材质由资源池持有，不跨Application共享。关闭弹窗/切换时释放当前模型实例和基础网格，代际标记丢弃迟到实例；关闭后停止姿态更新与连续渲染，模板与已加载资源留到本次图鉴页面退出。ResizeObserver及输入监听随预览宿主保留，离页统一解除；指针捕获关闭时释放。

离开路由依次释放实例、库模板、资源池、Application和材质，并解除观察器与监听。资源失败保留基础示意；预览相机独立，游戏跟随相机参数不变。新机关仅按部件轴心动画，固定底座不随动；跷跷板演示使用预置角度，正式游戏使用真实负载与单铰链，二者不混用。

## 文件

- `src/components/Obstacles.vue`：三列图鉴、筛选、搜索和详情。
- `src/components/ObstacleThumbnail.vue`：轻量静态SVG构图。
- `src/components/ObstaclePreview.vue`：预览宿主和播放/相机按钮。
- `src/game/obstacles.ts`：结构化障碍资料与组合关系。
- `src/game/obstacle-scene.ts`：共用构图与运动数据。
- `src/game/obstacle-preview.ts`：独立PlayCanvas预览与资源清理。
- `src/game/obstacle-library.ts`、`library-data.ts`、`library-visuals.ts`：共享模板、清单/姿态和分件驱动；`src/assets/obstacles/`：新增五类静态卡图。
- `src/game/advanced-preview.ts`、`advanced-library.ts`：高级八机关的预览姿态与共享模板实例。
- `src/main.ts`、`src/App.vue`、`src/style.less`：路由、导航、图鉴页面背景和窄屏导航。
