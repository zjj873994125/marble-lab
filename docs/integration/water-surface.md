# 两关水面材质

本文保留最初水面实现过程。当前工厂用于三关及图鉴，主题水色/非classic中性反射与最新黑海/金水以 [水色交付](water-themes.md) 为准；不将下文“一份反射”或固定蓝绿方案当作现阶段全部能力。

2026-09-14：本轮开发完成，按用户要求未运行本地测试、构建或浏览器试玩，实际细波强度、反光与设备表现尚未验收。用户最新要求自行推送，后续不代执行git add/commit/push或部署。

## 实际方案

`src/game/water-material.ts` 移除128px规则线条diffuse贴图，保留中深蓝绿底色。创建材质时，以固定种子的四组周期噪声生成512×512线性RGBA法线；边界取样与梯度循环衔接，不下载素材。

通过PlayCanvas 2.22.1的 `StandardMaterial.getShaderChunks(SHADERLANGUAGE_GLSL)` 局部覆盖 `normalMapPS`，使用引擎采样器占位符 `{STD_NORMAL_TEXTURE_NAME}`。按世界XZ坐标分别以10米和6米重复尺度采样同一张法线，第二层旋转后将梯度转回世界方向混合；不同池体尺寸保持相同波纹密度。法线扰动作用于现有照明与水材质反射，不移动顶点或碰撞。

水面独立使用一次生成的64×64×6柔和环境cubemap，产生环境明暗与轻量反光；不是真实赛道/钢珠倒影。材质保持不透明，未增加透明排序、折射、屏幕反射或整场景实时六面渲染。全局灯光、曝光、钢珠和轨道材质保持原值。

## 动态与生命周期

用户反馈首版水波太慢，本次仅将两层相位速度从 `[.006, .0035, -.0045, .0055]` 提高为4倍 `[.024, .014, -.018, .022]`（每秒UV偏移）。波纹尺度、强度、反射和冻结规则保持。此次未做视觉验证，不认定所有静止现象都由速度引起；低画质及减少动态仍按设计保持静态。

随后按用户要求增加设置抽屉的“水波速度”：0–10×、步长0.1，默认1×对应上面的提速后基准，0冻结当前相位。`Settings.waterSpeed` 随现有v3设置保存，两关共用；旧存储缺失或非法值取1，有限数值钳制到0–10，恢复默认回到1。只乘水视觉相位增量，不调整全局时钟/波纹尺度/物理或成绩规则。暂停、低画质、应用/系统减少动态的冻结优先于速度设置；暂停中修改会保存，继续游戏后生效。

`runtime.ts` 在每帧update中单独调用水面更新，即使菜单 `app.timeScale=0` 也可推进水视觉。水面使用 `performance.now()` 差值，完全独立于机关time和游戏elapsed；菜单/选关及playing仅在高画质且未启用应用/系统减少动态时缓慢移动。

暂停、结算、失焦、隐藏及减少动态冻结当前偏移，恢复首帧重新衔接时钟，超过250ms的间隔直接丢弃，不累加后台时间。重开只重置水面的时钟基准，不跳回零相位。关卡卸载再创建时重新生成本关材质与初相位。

低画质关闭第二层采样、降低法线强度并保持静态；减少动态在当前画质保留静态层次。切换画质只更新uniform，不每帧调用水材质 `material.update()`。动画循环复用Float32偏移数组，不生成纹理；材质只在创建时update一次。每关持有一张法线及一份六面环境贴图，随材质统一destroy。GPU纹理含mipmap约1.46MiB/关，不含驱动开销；生成用CPU缓冲/Canvas仅在创建时分配。
