# 首页开始与选关

本轮将顶部“开始”“挑战关卡”合并，保留首页、障碍图鉴和纪录导航。首页左侧主按钮下方提供“选择关卡”，两按钮同宽同高，保留橙色主按钮。选关改为弹窗，以局部斜视场景缩略图和关卡名组成卡片，显示临时选中状态及取消/确认。移除按钮下方“关卡编号/名字/新开一局”小提示，个人最佳保留。旧 `/#/levels` 重定向到 `/#/?choose=1`，首页自动打开新选关弹窗后消费该查询参数，不保留死链接或重复页面。

## 起局语义

- 无游玩记录：默认第一关，主按钮为“开始挑战”。选关入口始终可用，没有新增解锁限制。
- 只实际开始过第一关：仍显示“开始挑战”，可以通过下方的选关进入第二关。
- 实际开始过第二关或以后：再次打开页面默认加载上次实际开始的有效关卡，主按钮为“继续挑战”，下方为同尺寸“选择关卡”按钮，不额外显示关卡小提示。
- 弹窗内点击选项只修改draftLevelId，取消不改变当前关卡或上次游玩。确认后以显式选择为准，切换场景并在ready时直接新开这一关，不要求用户再次点击首页开始。
- 继续挑战开启该关的新一局，不恢复跨刷新检查点、计时或机关相位。现有局内暂停与继续不变。

## 保存与迁移

v3新增 `lastStartedLevelId` 和 `hasPlayedBeyondFirst`。仅 `startRun()` 通过场景ready、无启动错误及有效关卡判断后写入；预览、选关、看图鉴和设置保存不会被当成实际游玩。当前选中项继续以selectedLevelId保存，但刷新后优先上次实际开始的关卡，而非尚未起局的预览选择。

老存储没有实际开始字段时，按有效关卡的已有成绩推断：原selectedLevelId有成绩则作为兼容候选，否则选有最近有效日期成绩的关卡；没有任何成绩则第一关。已保存但已移除/未知的lastStartedLevelId回退第一关；未知关卡的历史桶继续保留。是否玩过后续关卡取已保存布尔值、已知关卡成绩或有效实际开始字段，不仅凭selectedLevelId判断。

原设置（含waterSpeed）、所有关卡/规则成绩、v1/v2只读原文保持。恢复默认只重置settings，不删除游玩进展。此新增首页进展不改变schema版本、关卡难度或成绩规则。

## 界面与生命周期

确认后将目标保存在首页组件的pendingTarget，等待现有GameCanvas加载完成；只有当前关卡与目标一致、ready且无错误、仍在首页菜单并保持弹窗打开时，才消费请求并调用startRun一次。加载期间禁用选项及重复确认；错误保留在弹窗，提供“重试并进入”。新增瞬时sceneLoadId和retrySceneLoad用于重新挂载失败场景，不通过runId伪造起局，未ready不写游玩记录。

取消、关闭弹窗、Esc、离开路由或卸载组件都会清空待启动请求；如果确认已切换但尚未进入，则恢复打开弹窗前的关卡。迟到ready没有待启动目标时只完成场景准备，不会自动进游戏。成功进入前先消费请求与恢复标记，防止首页卸载误回滚已选关卡。关闭回到首页时焦点返回选关按钮。

App继续使用原GameCanvas加载/释放边界，key由levelId与sceneLoadId组成；没有第二条游戏加载通道。主按钮未ready或有错误时仍禁用。当前桌面两按钮320×72px，字号20px、间隔16px，均为左侧文字、右侧箭头；短屏与窄屏尺寸见文末追加。通过Element Plus按钮直属span的全宽flex/space-between对齐。选关弹窗660px且受视口约束，桌面两张卡片并排，480px以下一列；选中卡片以橙色边框和勾选标识。只展示地图图与名字，没有难度/描述等附加文案。

文件：`src/state.ts`、`src/components/Lobby.vue`、`src/main.ts`、`src/App.vue`；本次弹窗修订实际改动state、Lobby与App，旧链接重定向沿用main已有实现，样式仅放Lobby组件中。新增 `src/components/LevelThumbnail.vue` 负责地图卡片，此前水速和图鉴本地修改继续保留，未改关卡、模型、玩家输入或物理。

按用户不检查与自行推送偏好，本轮未运行test/build/试玩，也未git add/commit/push。上述为实现行为说明，迁移、旧链接、移动端排版、焦点、确认后加载/失败重试/取消竞态的运行效果尚未验证，不宣称验收通过。

## 局部斜视场景缩略图

用户否定整关俯视线路图后，LevelThumbnail原位改为首页式斜视局部构图：教学关选取起点侧轨道转弯、摆锤及附近底座/支撑；水上冲关选取十字旋转台、两端接驳岛与旁侧连接轨道。采用固定近景取景范围，不再以整关包围盒fit-all，画面边缘允许自然裁取邻接轨道，两关有明显不同的代表机关。

静态来源仍是各自LevelConfig的轨道/机关位置和尺寸；旋转盒体绘制多个立体面，圆柱分段绘制，按面朝向着色并投射到蓝绿水面阴影。教学关支撑/底座读取已有图元，第二关静态GLB中的支撑没有独立配置，缩略图在真实台面下补同风格轻量示意支撑/底座，不改运行场景或碰撞。摆锤和十字取固定参考相位，钢珠仅作场景比例示意；这是本地生成的SVG场景插画，不是实际GLB截图或物理验证结果。

SVG内置水面渐变、钢珠渐变与软阴影，每个组件独立id防止资源引用串图；不为卡片启动WebGL/Ammo、不下载图片、不裁剪用户浏览器截图。弹窗仍只有图片、关卡名与勾选状态；draft临时选择、取消恢复、确认后等待ready只start一次的逻辑不变。首页右下艺术字、状态胶囊、游戏相机和模型不变。本轮未运行test/build/浏览器试玩，斜视缩略图实际观感尚未验收。
