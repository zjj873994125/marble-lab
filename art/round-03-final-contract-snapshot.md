# CODE-03 · 成绩版本与机械锤协议

日期：2026-09-11。状态：成绩兼容、X 轴移动、最终胶囊玩具锤和水池显示已实现；最终配套配置已启用，12 项测试与构建通过。完整运行和第二轮合并验收见 `round-03-validation.md`。

## 版本与启用

- `LevelConfig.rulesVersion` 可选值为 `'classic' | 'open-hammer' | 'flat-hammer'`；省略等同 `'classic'`。因此代码先上线、历史配置没有该字段时，仍记录旧玩法。
- LEVEL-03 在代码就绪、平台方案经统筹决定后，一次性写入新配置：指定两栏及碰撞删除、平台运动数据、胶囊形玩具锤头、`rulesVersion: 'open-hammer'`；不能先单独切版本标记再逐项改玩法。
- 新版资源未到位时允许明确的基础几何暂态：`visuals: null`，`pendulum.visuals: null`。它使用新版碰撞与规则、对应新版成绩，不是旧玩法。
- 新存储键为 `marble-lab-v2`，保存 `schemaVersion: 2`、设置，以及按各规则标识分开的成绩桶（classic/open-hammer/flat-hammer）。原 `marble-lab-v1` 只读、不删除或覆盖，保留原始内容可恢复。
- v2 尚不存在时读取 v1 的设置和无版本成绩，成绩仅归 classic；首次有保存动作时写 v2。已有有效 v2 时不再次合并 v1，避免重复迁移。当前最佳/排序/结算只使用配置对应桶；另一版本的纪录仍可查看。各桶沿用最快 20 次上限，奖牌 35/55/90 秒不变。
- 保存失败保留内存状态并提示，不能为了迁移清空数据。新旧交替读取、重复保存和拒绝写入需测试。当前仍是单关规则分桶，不新增多关卡或云端。

## 当前平端玩具锤（用户验收后修正）

用户要求 ±Z 短击打端是平面，不能保留半球；头包络 [.9,.9,1.36]、原中心轨迹、锚点、柄与运动参数保持。当前同名源文件/GLB 原位修改，不新建版本或备份。

```ts
ball: {
  name: 'Pendulum', type: 'cylinder', collisionAxis: 2,
  position: [-5.5, 4.3, -4],
  size: [.9, .9, 1.36], material: 'orange'
}
```

`collisionAxis` 同时定义圆柱显示与碰撞长轴；默认1（Y），本锤显式2（Z），普通柄与支撑不变。原生碰撞参数 axis=2、radius=.45、height=1.36，height 是两平端之间的总长；Ammo 使用 btCylinderShapeZ，半尺寸 [.45,.45,.68]，不减去端帽。基础回退同样为有两个平面圆盘的 Z 圆柱，并测试端盘半径 .45；不是半球端。

当前锤头 GLB 仍为 `hammer-head-toy-round-03.glb` / HammerHead，+Y 指向锚点，±Z 为平击打面；主体约 .035 米窄倒角可以位于简化圆柱包络内。模型与代理同尺寸、同姿态。胶囊版本已是历史结果，不能用旧32.83秒或旧模型哈希验收本次修正。

护栏由LEVEL同步：内侧起点栏中心 [-8.45,3.53,2.25]、尺寸 [.12,.26,9.5]，Z端点 [-2.5,7]；其他护栏保持。该栏已先行写入的阶段视为配套暂态，不回滚，也不按假设迁移暂态产生的成绩。

两处碰撞变化使用 `rulesVersion:'flat-hammer'`，保留 classic/open-hammer 全部记录及设置；归档界面按各旧桶分别显示，不混合旧桶排名，不删除或移桶猜测旧数据。代码准备先行、配置未切版本时仍按原标识记录。MODEL 文件名保持原样，成绩标识与模型备份无关。

## 锤柄数据与资产

ART-03 交付 `public/models/hammer-handle-toy-round-03.glb`，节点 `HammerHandle`。原点为柄的中点，局部 Y 为长度轴，模型长度固定 1 米，Y 范围 `[-.5,.5]`，直径/最大横向宽度 `.12` 米，X/Z 范围 `[-.06,.06]`。运行时按锚点与头中心之间的实际距离伸缩 Y；径向尺寸不随柄长变化。可以使用多材质机械杆/握持表面，但不要做会因轴向拉伸而错位的独立固定长度大端帽。

柄上端连接原锚点，下端到锤头中心并埋入头内；不让柄悬空或伸出头底。运行时统一让头与柄的 +Y 朝向锚点；柄位置取两点中点，长度取距离。原 `rodWidth=.12` 保持，柄仅显示，不新增杆身碰撞。

配置增加可选 `pendulum.visuals`：

```ts
visuals: {
  head: 'hammer-head-toy-round-03.glb',
  handle: 'hammer-handle-toy-round-03.glb'
}
```

两份 GLB 均自包含，不导出相机/灯光/玩法脚本。使用既有 `BASE_URL + models/` 资源入口。两个锤子资源全部成功后才隐藏基础头和柄；任意一个失败，释放已加载资源并保留可玩的基础平端圆柱锤头+柱形柄，不影响轨道与平台。运行时销毁统一释放模型实例和资产。

## 平台 X 轴方案（统筹已确定，代码已支持）

当前同高 Z 往返无法既完全退出缺口又避开两岸体积，该方案已撤下。

`platform.axis?: 'x' | 'z'`（省略 z）、`centerX?: number` 已支持。新版使用 `axis: 'x'`、`centerX: 8`、`centerZ: -.35`、`amplitude: 3.4`、`angularSpeed: 1.25`，主体尺寸与高度不变。运动为 `x=8+3.4*sin(1.25*t)`，Z 固定 -.35；模型、代理和条纹同步 X。条纹可由关卡转为沿 Z 的 `[.17,.035,2.6]`，导轨由配置转为 X 方向，不能保留旧运动暗示。

两端 X 中心 4.6/11.4，完整露空每侧约 .78393 秒，周期约 5.02655 秒，最大速度 4.25 米/秒。几何计算之外，已完成两周期采样、两端露空、.2/.3 米接缝登离台、露空掉落与 CP2 重生实测，证据见最终验收报告。

## 水池显示（已支持）

- `MaterialName` 新增 `water` 和 `poolEdge`；水体使用 water，池沿使用 poolEdge，池底按 LEVEL/ART 交接沿用既有 dark，不新增多余材质键。
- 美术水色候选为 `#245F69`，在现有灯光/色调映射下校准运行时 diffuse 输入为 `#123C45`，池沿 `#617B80`；水为不透明低高光，不依赖实时反射。运行时生成一张 128×128 的轻量周期纹理，低对比水纹缓慢平移，不加载外部素材或模拟流体。
- 高画质且未减少动态时，游戏推进带动水纹；低画质、应用或系统减少动态时固定相位为 0。两种模式保留同一深色基调，明度差不依赖阴影。已用高/低画质及减少动态截图核验。原文字区域仅加浅底板保护可读性。
- **唯一几何来源为 LEVEL-03 的 staticObjects**：替换无碰撞 Ground 并配置池底、水面、池沿；都不设置 body/refinedVisual。运行时只创建材质，不另造一份池水，GLB 不烘焙水池。
- LEVEL/ART 候选水面顶 Y=-.1，中心 `[2.5,-.11,0]`、尺寸 `[72,.02,56]`；池底及四根池沿按关卡交接。保持 fallY=-.5、旧支撑和赛道高度，允许脚座浅浸入水，无浮力、水阻或额外承托。
